# tgnews — вместе прогон: каналы -> GLM -> Saved Messages

Что делает:
1. Через Telethon (твой **юзер-аккаунт**, не бот) читает каналы из `channels.txt` в реальном времени.
2. Фильтрует: голые ссылки, реклама, посты без текста — скип. Дубли (Jaccard ≥ 0.6 по токенам за 6 ч) — скип.
3. Воркер раз в `RATE_SECONDS` (по умолчанию 180 с = 20 постов/час) в окне 7:00–22:00 Europe/Berlin:
   прогоняет самый свежий кандидата через `opencode` (модель из `.env`) по `prompt.txt`.
4. В твои **Saved Messages** летит пара:
   - соо 1: медиа альбом/фото/видео из первоисточника + переписанный текст (50–248 симв.);
   - соо 2: форвард оригинала с канала.
5. Дальше ты руками: копируешь сообщение 1 в свой канал.

## Деплой на сервер
```bash
# локально
scp -r ~/tgnews user@server:/root/
ssh user@server
cd /root/tgnews

# 1. env: API_ID/API_HASH необязательно — если пусто, телега считает нас Telegram Desktop
#    (публичные ключи уже вшиты). DRAFT_TARGET = username твоего тг-бота из BotFather
cp .env.example .env && nano .env
# 2. opencode auth внутри контейнера (один раз):
docker compose build
docker compose run --rm -it app opencode auth login
# 3. логин телеги (один раз, понадобится код из TG):
docker compose run --rm -it app python -m app.bootstrap
# 4. поднять в фоне:
docker compose up -d
docker compose logs -f
```

## Подстройка
- `RATE_SECONDS=180` → 20/час; поставь 360 → 10/час.
- `channels.txt` — доп.каналы без рестстра и перезапуска кода: `docker compose restart`.
- `prompt.txt` — правишь стиль; пеня: `docker compose restart`.
- Кнопок деплоя в канал нет вообще — всё руками (как хотел).

## Известные ограничения (принимаются сознательно)
- Дубли на разных языках (SU-34 история на EN/ES/AR одновременно) токен-дедупом не ловятся — модель не заморачивается, отсекаешь руками при валидации.
- Человекоба! Формат выбора: просто копипаст в канал, никакие изменения остальное не парсят.
- Модель иногда может писать 40-49 или 250+ симв. — хард-трим в sender'е, но содержимое может чуть пострадать; правишь руками.
